
# Практическая работа №2 — Инвентарь героя

## Описание

Консольная программа для управления инвентарём героя.
Реализованы добавление и удаление предметов, использование зелий,
поиск по имени и просмотр сводки инвентаря.

## Технологии

- Java 21
- Apache Maven 3.9+
- IntelliJ IDEA

## Вариант

Вариант А — Воин.

- Ёмкость: 4 предмета
- Максимальная масса: 6000 г
- Начальные предметы: Меч, Щит, Зелье

## Сборка и запуск

Из корня проекта:

```bash
mvn compile
mvn exec:java
```

## Начальная сводка

- Предметов: 3 из 4
- Масса: 6000 из 6000 г
- Стоимость: 200 монет

## Проверки модели

1. Добавление предмета сверх лимита массы: отказ, состояние прежнее.
2. Удаление предмета: оставшиеся элементы сдвигаются влево.
3. Использование зелья: предмет удаляется, масса уменьшается на 500 г,
   стоимость — на 20 монет.
4. Поиск по имени: регистр не учитывается, исходные имена не меняются.

## Эксперимент с лимитом массы

При лимите 6001 г добавление «Перо», potion, 1 г, 0 монет
должно пройти, если свободна ячейка.
Ожидаемая масса после добавления: 6001 г, стоимость: 200 монет.

При исходном лимите 6000 г добавление должно быть отклонено.
После отказа масса остаётся 6000 г, стоимость — 200 монет.

## Эксперимент со снимком

Рабочий snapshot() возвращает копию массива ссылок.
Замена элемента снимка на null не изменяет массив инвентаря.

При временном возврате внутреннего массива изменение снимка
затрагивает исходный инвентарь. Причина — оба имени ссылаются
на один массив. Исправление — Arrays.copyOf(items, size).

## Итог

Ошибочные экспериментальные изменения не должны оставаться
в финальной версии. Перед сдачей следует повторить проверки
на восстановленном коде.
