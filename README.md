# Практическая работа №3 — Герой и его рюкзак

**Вариант А — Воин**

## Цель работы

Изучить принципы объектно-ориентированного программирования (ООП), инкапсуляцию, композицию объектов и взаимодействие классов в Java.

## Описание проекта

Программа моделирует двух героев — Алию и Данияра, у каждого из которых есть собственный рюкзак для хранения предметов.

Рюкзак имеет ограничения по количеству предметов и общей массе. Если предмет не помещается в рюкзак, программа отклоняет его добавление.

## Используемые классы

- **Main** — запускает программу, создаёт героев и предметы, выполняет проверки и выводит результаты.
- **Hero** — описывает героя, хранит его имя и рюкзак, предоставляет методы для подбора предметов и получения информации о содержимом.
- **Inventory** — управляет предметами в рюкзаке, проверяет ограничения по вместимости и массе, вычисляет общую стоимость и массу.
- **Item** — описывает предмет с названием, типом, массой и стоимостью.

## Основные возможности

- Создание героев с индивидуальными рюкзаками.
- Добавление предметов с проверкой вместимости и ограничения по массе.
- Подсчёт количества предметов, общей массы и стоимости.
- Получение снимка содержимого рюкзака без раскрытия внутреннего массива.
- Независимость рюкзаков разных героев.
- Обработка `null` и проверка корректности имени героя.
- Проверка граничных значений массы.

## Результаты проверки

Программа успешно выполнила основные сценарии:

- Алия подобрала меч, щит и зелье.
- Попытка подобрать перо была отклонена из-за ограничения по массе.
- Данияр подобрал карту и факел.
- Попытка подобрать перо Данияром была отклонена.
- Рюкзаки героев остались независимыми.
- Дополнительные проверки завершились сообщениями `[OK]`.

## Используемые технологии

- Java 21
- Apache Maven
- IntelliJ IDEA
- Git и GitHub

## Запуск программы

1. Открыть проект `inventory03` в IntelliJ IDEA.
2. Убедиться, что выбран JDK 21.
3. Открыть файл `src/main/java/kz/javaworkshop/Main.java`.
4. Нажать зелёный треугольник рядом с методом `main`.

Также проект можно собрать через Maven командой:

```bash
mvn compile
```
